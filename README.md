## Hi, I'm Aaditya

Backend engineer based in Navi Mumbai. I like problems where the hard part is
what happens under load — services that have to stay up, queues that have to
drain, and knowing which one broke when something goes wrong at 2am.

Mostly Python and FastAPI, sitting on MySQL, MongoDB and Redis, with NSQ moving
work between things. I reach for React when the frontend needs me, and I'm
increasingly interested in giving language models safe, structured access to
systems that were never designed for them.

### Things I've built

**[netflix-portfolio](https://github.com/adityashetty35/netflix-portfolio)** —
my portfolio as a Netflix clone. Visitors pick a profile — Recruiter, Developer,
Adventurer — and the site reshapes around what they came for, which turns "one
page for several audiences" from a compromise into the feature.

**[lapa_file_store](https://github.com/adityashetty35/lapa_file_store)** — a
Python file-storage service, part of a self-hosted backend stack with its own
auth layer and typed TypeScript client libraries.

**[graylog](https://github.com/adityashetty35/graylog)** — a Docker Compose
stack for running Graylog with MongoDB and OpenSearch locally, for when you want
centralized logs in development without assembling the whole thing by hand.
